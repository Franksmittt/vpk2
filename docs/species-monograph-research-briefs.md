# Species monograph research briefs

Reference pack to build full guide pages like `GreaterKuduGuide.tsx` for each quarry species.  
**Greater kudu** is already shipped; the rest use this outline.

## Monograph section map (match kudu)

1. **Hero** – nickname, scientific, one emotional hook, CTA to reserve + anchor to fieldcraft.
2. **Overview** – two short columns: cultural / ecological role on a Waterberg-style property; what the page covers.
3. **Taxonomy** – tribe, genus, subspecies or morph notes, naming etymology if interesting.
4. **Form** – size, mass, sexual dimorphism, horns/tusks, coat, gait signatures.
5. **Range & diet** – habitat edges, water dependence, seasonal shifts, key forage.
6. **Social / rut / vocal** – herds, territoriality, breeding, alarm signals.
7. **Predation** – main predators, flight / fight tactics.
8. **Hunting** – glassing, stalk, ambush, tracking cues; ethical notes for fenced / intensive systems.
9. **Rifle & shot** – align with `data/species.ts` caliber + Rowland Ward; shot placement basics (always defer to PH).
10. **Meat / culture** – table fare, Afrikaans names, folklore if any.
11. **Quick facts table** – pull from `QuarrySpecies` + add weight / height ranges.

**Legal / ethics:** South Africa dangerous game minimum **.375** for listed species; always state **PH has final call** on age, quota, and shot.

---

## Global South African context (append to every species)

- Many species are **abundant on private game farms** and in national / provincial parks; several are **extralimital introductions** (not native to every province where they are hunted).
- **Hybrid risk:** blesbok / bontebok; blue wildebeest / black wildebeest; eland subspecies where both occur. Worth one sentence on **genetic integrity** for ranching readers.
- **Colour variants** (dapple impala, golden wildebeest): same species biology; add a short **“Ranch note”** on selective breeding and **trophy vs meat** value without moralizing.

## 1. Blue wildebeest – *Connochaetes taurinus*

| Field | Notes |
|--------|--------|
| Tribe | Alcelaphini (with hartebeest, topi, tsessebe). |
| SA status | Widespread; **Least Concern** regionally (SANBI / EWT assessments). |
| Size | Heavy gnu-type build; bulls commonly **~250 kg** class, cows lighter; shoulder **~120–150 cm** range in field guides. |
| Horns | Cow-like profile; heavy bases; used in ritual fighting; **width** often trophy metric. |
| Habitat | Shortgrass plains, savanna, open woodland; strong **grazer**; often near water; classic **mixed herds** with zebra in large systems. |
| Movement | **Alcelaphine** endurance; can string out when disturbed; tends to **run then stop and stare**. |
| Hunting | Open-country **spot-and-stalk**; wind critical; shots often **150–250 m+** on open veld; flat-shooting cartridge helps. |
| Rifle | Per roster: **.375 H&H recommended** tier for heavy animals; many farmers take bulls with **.30-06 / .300** with **good bullets**. |
| Shot | Broadside **heart-lung**; avoid marginal raking angles on heavy shoulder. |
| Meat | Dark, strong; biltong popular; culturally central as **plains game**. |
| Research hooks | Hybridization with **black wildebeest** where ranges overlap; migration history vs **fenced water** (SANBI narrative). |

**Sources to cite in footnotes later:** SANBI species status; EWT blue wildebeest project; Estes & East wildebeest status reports.

## 2. Impala – *Aepyceros melampus*

| Field | Notes |
|--------|--------|
| Subspecies in SA | Common impala **A. m. melampus** (broad distribution). |
| Size | Rams **~75–92 cm** shoulder, **~53–76 kg**; ewes smaller; hornless females. |
| Horns | **Lyre-shaped**, strongly ridged, **~45–92 cm** length in literature. |
| Feeding | **Mixed feeder**: graze green grass, browse shrubs, pods; edge species near water. |
| Social | Female herds, bachelor herds, territorial rams in rut; **allogrooming** prominent. |
| Anti-predator | **Stotting / pronking-style leaps**, explosive scatter; alarm snorts. |
| Rut | Often **post-rains** peak; intense male chasing. |
| Hunting | Very common plains game; wood-bush edge stalks; often **first animal** for international clients. |
| Rifle | Roster: **.243 / 6.5 Creedmoor** class adequate with **premium bullets**; shot typically close. |
| Shot | Small target: **broadside heart-lung**; avoid high “deer-behind-shoulder” habit if angle is quartering. |
| Meat | Excellent venison; mild if handled cold-clean. |

## 3. Dapple impala – *Aepyceros melampus* (colour morph)

| Field | Notes |
|--------|--------|
| Biology | **Identical** to impala; **recessive / line-bred** pale or patchy coat on some ranches. |
| Copy angle | **Ranch note:** morph value is **aesthetic / rarity**; management same as impala; discuss **record-keeping** if selling breeding stock. |
| Hunting / rifle | Same as impala; **positive identification** so a common impala is not mistaken. |

## 4. Gemsbok – *Oryx gazella*

| Field | Notes |
|--------|--------|
| Range | Arid / semi-arid **Kalahari-Namib** belt; widespread on SA ranches. |
| Size | Large oryx; bulls often **~180–240 kg**, cows **~100–210 kg**; shoulder **~1.1–1.2 m**. |
| Horns | **Both sexes**; cows often **longer, thinner**; bulls **thicker bases**; trophy judging is **not** “male only.” |
| Adaptation | **Heat-exchange** facial pattern; can **tighten water budget** via succulents / melons / deep roots; long **kidney efficiency** narrative. |
| Herds | Gregarious; nursery bands; **wounded animal dangerous** (spear with horns). |
| Hunting | **Spot-and-stalk** in open scrub; long shots common; **bonded / partition** bullets. |
| Rifle | Roster: **.30-06 / .300** class; minimum **.270** sometimes quoted for perfect placement. |
| Shot | **Heart-lung**; on quartering-away mind the **forward shoulder** mass. |
| Meat | Excellent, lean; biltong staple in many regions. |

## 5. Warthog – *Phacochoerus africanus*

| Field | Notes |
|--------|--------|
| Subspecies SA | **P. a. sundevallii** (southern warthog). |
| Size | Boars **~60–150 kg** (wide range by region), sows smaller; shoulder **~63–85 cm**. |
| Tusks | **Upper canines** large, curved; **lower canines sharpen** against uppers; digging is **snout + feet**, not tusks. |
| Groups | **Sounders** (sows + young); bachelor groups; boars often solitary. |
| Shelter | **Aardvark burrows**, erosion pipes; enters **rear-first**. |
| Daytime | **Diurnal**; kneels to graze short grass; **mud wallow** at water. |
| Predators | Lion, leopard, wild dog, hyena; **sows defend piglets** aggressively. |
| Hunting | **Still-hunt** waterholes / short grass; **tough for size**; shot on **broadside** low on shoulder or **neck** only with PH approval. |
| Rifle | Roster: **7×57 / .308** class; shot often **under 100 m**. |
| Meat | **Pork-like** if cleaned; popular braai cuts; **no taboo** in SA hunting culture. |

## 6. Blesbok – *Damaliscus pygargus phillipsi*

| Field | Notes |
|--------|--------|
| Endemic | **South Africa** endemic subspecies; recovered from near-collapse via **conservation + private sector**. |
| Status | **Least Concern**; very large numbers on **private wildlife ranches**. |
| Name | **“Bles”** = blaze on face. |
| Size | Field guides often **~85–95 cm** shoulder; **~60–70 kg** cows, **~70 kg+** rams; horns **lyrate**, **~30–40 cm** class. |
| Hybrid | **Do not mix with bontebok** (*D. p. pygargus*); fertile hybrids threaten **pure breeding** programs. |
| Habitat | **Highveld grassland**, open plains; **grazer** on short grass; visible at distance. |
| Hunting | **Stalk** or **ambush** at water; often **shooting sticks** on open veld. |
| Rifle | Roster: **.308 Win**; many use **.243–7mm** with good shot placement. |
| Meat | Fine-grained; popular **biltong** animal. |

## 7. Bushbuck – *Tragelaphus sylvaticus* (southern / Cape bushbuck)

| Field | Notes |
|--------|--------|
| Taxonomy | Split from **northern bushbuck** (*T. scriptus*) in modern treatments; check **IUCN / SANBI** wording you prefer on site. |
| Size | Rams **~45–80 kg**, ewes lighter; shoulder **~64–100 cm** (population variable). |
| Horns | Rams only; **spiral**, usually **~1+ twist**, **~30–55+ cm** in big rams. |
| Habitat | **Riverine thicket**, forest-savanna mosaic, dense bush; **not** a plains animal. |
| Behaviour | Often **solitary** or paired; **freeze** then bolt; strong **territorial** marking. |
| Hunting | **Still-hunting** thick cover; **short ranges**; easy to **wound and lose**; PH essential for **dog recovery** policy. |
| Rifle | Roster: **.308**; dense cover suggests **low-power optic**. |
| Shot | **Broadside** heart-lung; angles tight in brush. |
| Predators | Leopard, hyena, wild dog, python (young). |
| Meat | Eaten locally; strong if not bled quickly. |

## 8. Cape buffalo – *Syncerus caffer*

| Field | Notes |
|--------|--------|
| Subspecies | **S. c. caffer** in southern Africa (Cape buffalo). |
| Dangerous game | **Legal minimum .375** (and listed equivalents) in SA; **soft-point first**, **solid follow-up** PH doctrine. |
| Size | Massive; cows and young in **herds**; **dagga boys** solitary or small bachelor groups. |
| Senses | **Hearing + smell** excellent; **vision** moderate; **wind** discipline non-negotiable. |
| Shot | **Heart-lung / shoulder-breaking** broadside per PH; **avoid** casual head shots; **follow-up** plan is life safety. |
| Behaviour | **Wounded buffalo** is the cliché for a reason; **circle back** in thick stuff. |
| Ecology | **Grazer** in savanna-bushveld mosaics; **mud wallow**; strong **herd defense** against lions. |
| Rifle | Roster matches regulation: **.375 H&H minimum** framing. |
| Meat | Eaten in some cultures; often **not** primary motivation vs **trophy / experience**. |

## 10. Springbok – *Antidorcas marsupialis*

| Field | Notes |
|--------|--------|
| National symbol | **South Africa’s national animal**; rugby identity; cultural weight. |
| Subspecies | **A. m. marsupialis** smallest; **hofmeyri** larger in west; know which you stock on farm. |
| Size | **~71–86 cm** shoulder; **~27–42 kg** typical (subspecies spread). |
| Horns | **Both sexes**; **S-shaped**, ringed; females shorter / thinner. |
| Pronking | **Stiff-legged bounds**, dorsal crest and rump patch **flashed**; anti-predator + social display. |
| Speed | **~88 km/h** class in references; sustained flight across open veld. |
| Feeding | **Mixed feeder**; shifts graze/browse with season. |
| Hunting | **Long shots** on open Karoo / Kalahari-type veld; **.243** classic; wind drift matters. |
| Rifle | Roster: **.243 Win**; premium **varmint / deer** bullets adequate with placement. |
| Meat | **National dish** associations; biltong, droëwors. |

## 11. Red hartebeest – *Alcelaphus buselaphus caama*

| Field | Notes |
|--------|--------|
| Tribe | Alcelaphini with wildebeest. |
| Nickname | **“Hardebees”** folk etymology vs Dutch **hartebeest**. |
| Shape | **High shoulders, sloping back**, elongated face; **cursorial** build. |
| Horns | **Both sexes**; heavily ringed, **lyre** shape; males thicker. |
| Size | Literature: males **~150 kg**, females **~120 kg**; shoulder **~1.2–1.35 m** (sources vary). |
| Speed | **~55 km/h+**; **zigzag** flight path. |
| Senses | **Smell + hearing** strong; **eyesight** weaker than some plains species. |
| Hunting | **Open plains**; often **longer shots**; **flat cartridge** (.270, 7mm, .300) popular. |
| Rifle | Roster: **.30-06**. |
| Meat | Good venison; regional **biltong** animal. |

## 12. Red lechwe – *Kobus leche*

| Field | Notes |
|--------|--------|
| SA context | **Not historically endemic** to most of SA; **introduced** on wetlands / irrigation farms (**Free State, EC, KZN, Limpopo, NW** etc.). |
| Adaptation | **Water-associated** *Kobus*; hind legs longer; hooves **spread on mud**; strong **swimmer**. |
| Horns | **Rams only**; **lyrate**, sweep back then forward; **SCI / RW** scoring familiar to PHs. |
| Size | Hunting sources often **~80–120 kg** rams class; shoulder **~85–100 cm** (verify on farm). |
| Behaviour | **Herd**; flight to water; **midday loafing** in shallow water / shade. |
| Hunting | **Spot-and-stalk** on floodplain margins; **rubber boots** reality; **bullet drop** if misjudging distance over water glare. |
| Rifle | Roster: **.270 Win**; **premium soft points**. |
| Shot | **Low on shoulder** broadside; confirm **leg depth in water** before shooting. |

## 13. Livingstone eland – *Taurotragus oryx livingstonei* (often *livingstonii* in texts)

| Field | Notes |
|--------|--------|
| Subspecies | One of **three** eland subspecies; **striped** variant; range **Zambezian** woodlands into **northern SA introductions**. |
| Size | Largest antelope; bulls **400–942 kg** extreme range in ADW / Wikipedia synthesis; **typical hunted bull** still **massive** vs kudu. |
| Horns | **Both sexes**; **tight spiral** at base, straighter distally; cows’ horns shorter. |
| Behaviour | **Nervous**, long flight distances; **crepuscular** bias; can **jump** serious fences. |
| Hunting | **Multi-day** stalk narrative is honest; **quiet wood-bush** approach; often **.338 / 9.3 / .375** preferred by PHs even if legal minimum lower. |
| Rifle | Roster: **.375 H&H** (matches heavy animal ethics). |
| Shot | **Heart-lung**; massive body can **soak** poor bullets. |
| Ranch note | **Hybridization** with **Cape eland** where both occur; **pure strain** marketing. |
